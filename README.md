# Read with me

Приложение для обучения чтению по-английски по методу **synthetic phonics** — для русскоязычных семей. Мама ведёт занятие, ребёнок читает. 15 минут в день, 12 недель — и ребёнок читает слово, которое видит впервые.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Старт** | Методика для родителя: как произносить звуки, как читать столбики, живой маршрут на 12 недель |
| **Наборы 1–4** | 26 звуков в порядке частотности, а не алфавита |
| **Диграфы** | `th` → `ch` → `sh` → `ph` — `th` первым, ему нужно больше всего времени |
| **Немая e** | Тренажёр пар `cap → cape` |
| **Тренировка** | Повтор вперемешку, слова-обманщики, диктант, пары гласных |
| **Карточки** | Печать 9 карточек на A4 с пунктиром для разреза |

Ключевые механики:

- **Таблицы по столбикам** — в столбике одна гласная, меняются только согласные. Кнопка ▶ подсвечивает слова по очереди и держит темп.
- **Спиннер** — три барабана (onset / vowel / ending) останавливаются по очереди слева направо, слово собирается в порядке чтения.
- **12 рассказов** — каждый использует только пройденные звуки.
- **Слияние озвучено.** Кнопка «Слить по звукам» играет слово растянутым вдвое — «сссаааат» — и следом в обычном темпе. Слияние и есть тот навык, ради которого метод называется синтетическим; раньше кнопка только двигала подсветку и произносила готовое слово.
- **Звуки на фишках набора.** Те, что тянутся голосом, можно послушать. Взрывные `/p/ /b/ /t/ /d/ /k/ /g/` помечены «вы» и остались за взрослым: без гласной они не произносятся, и синтез даёт «пэ», «кэ».
- **Беглость отмечает родитель**, кнопкой под столбиком. Маршрут на 12 недель закрашивается по этим отметкам, а не по кликам ребёнка: клики слишком легко набрать, не читая.
- **Прогресс** сохраняется в `localStorage`.

## Озвучка

Голос — **Sophia** (ElevenLabs, `LM5QaByxyWDmNhcQTYiS`): британский, polished RP.
Выбран не по вкусу, а по таблицам: звуки в `data.js` записаны как `/ɒ/`
(«губы кружком»), `/əʊ/`, `/ʌ/`, `/iː/`, `/juː/` — это RP. Американский голос
в столбике `o` даёт неогублённый `/ɑ/`, а в паре `hop → hope` — `/oʊ/` вместо
`/əʊ/`, то есть ребёнок слышит не тот звук, который нарисован в шапке столбика.

Темп записи — **0,7×** от обычной речи. Это нижняя граница, которую принимает
ElevenLabs: на `speed=0.65` API отвечает 400. Если понадобится ещё медленнее,
`--speed` сам отрендерит на 0,7 и дотянет остальное через `rubberband` при
сборке — он тянет длительность, не трогая высоту голоса, и это заметно чище,
чем `playbackRate` в браузере, который растягивает на лету на каждом слове.
Ползунок в ⚙︎ — добавка поверх записанного темпа, а не он сам; подпись под ним
показывает, что получится на выходе.

Записывается три вида звука, всё заранее и всё в Cloud Storage проекта:

| Ключ в манифесте | Что это |
|---|---|
| `sat` | обычная запись слова или строки |
| `blend:sat` | то же слово, растянутое вдвое для слияния |
| `sound:/s/` | отдельный звук |

Растянутые копии делаются из готовых записей через `rubberband` — к API не
обращаются и кредитов не стоят.

Файлы лежат тут:

```
gs://violet-3e5a8.firebasestorage.app/audio/<слово>-<хеш>.mp3
```

Приложение читает `public/audio/manifest.json` — это `{строка: URL}` плюс
голос, модель и темп — и играет готовый файл. Ключей в браузере нет, в
ElevenLabs сайт не ходит. Если строки в манифесте не нашлось, включается голос
браузера.

**Почему бакет, а не `public/`.** Аудио живёт отдельно от хостинга: `firebase
deploy` его не трогает, деплой остаётся лёгким, а Vercel и Firebase отдают один
и тот же звук. В имени файла — хеш содержимого, поэтому `Cache-Control` стоит на
год: перезаписанная запись получает новый URL.

**Предзагрузка.** При открытии набора его озвучка уезжает в кэш браузера, дальше
её отдаёт service worker — второй проход по столбику идёт офлайн и мгновенно.

### Обработка

Каждая запись подрезается по краям и выравнивается **одним статическим
усилением** к −24 дБ, с потолком по пику −1 дБ.

Здесь напрашивается `loudnorm`, и это ловушка. Слово `sat` длится 0,7 с и
наполовину состоит из тишины, поэтому интегрированная громкость у него читается
как −30 LUFS — не потому, что запись тихая, а потому, что короткая. `loudnorm`
верит этой цифре и тянет до −16 LUFS: +12…+21 дБ динамическим усилением, пик в
потолок, наружу лезет придыхание и шум кодека, а взрывные `/p/ /t/ /k/`
расплющиваются — ровно те, которые метод и ставит. Выравнивания при этом всё
равно не выходит: слово и фраза расходятся на 4,7 дБ. Статический сдвиг даёт
разброс 0,1 дБ и не трогает динамику.

### Пересобрать озвучку

```bash
cp .env.example .env          # ELEVENLABS_API_KEY + путь к ключу сервисного аккаунта
npm install                   # firebase-admin, нужен только скрипту
npm run audio:dry             # план и стоимость, ничего не тратит
npm run audio                 # догенерирует недостающее и зальёт в бакет
```

| Флаг | Что делает |
|---|---|
| `--dry` | показать план и оценку, ничего не генерировать |
| `--limit=3` | проверить всю связку на трёх файлах |
| `--force` | перезаписать всё заново |
| `--speed=0.6` | темп чтения; ниже 0,7 дотягивается rubberband |
| `--voice=<id>` `--model=<id>` | другой голос или модель |

Скрипт идемпотентен: сверяет манифест с содержимым бакета и тратит кредиты
только на новые строки. Сменились голос, модель или темп — манифест сам себя
обесценивает и переозвучивается всё, так что `--dry` не соврёт «уже готово».
Манифест пишется после каждого файла, обрыв связи ничего не теряет. Осиротевшие
файлы из бакета удаляются — но только после полного прохода: при `--limit`
манифест заведомо неполный, и уборка по нему снесла бы всё остальное.

**Стоимость.** Считается по факту, из заголовка `character-cost` в каждом
ответе. Замер даёт около **0,27 кредита на символ** для `eleven_multilingual_v2`,
а не 1 — весь курс на 3 373 символа обходится примерно в **950 кредитов**.

`public/audio/*.mp3` — локальный кэш генератора, в git не идёт. Источник правды
— бакет и `manifest.json`.

**Ключи.** `.env` и `service-account.json` в `.gitignore`. В опубликованный сайт
не попадает ни то, ни другое.

> Отдельные звуки (`/k/`, `/t/`, `/æ/`) намеренно не озвучиваются: любой синтез
> читает их как названия букв — «си», «ти» — а это ровно та ошибка, против
> которой построен метод. Звуки произносит взрослый по подсказкам в карточке
> набора.


## Деплой

### Vercel

```bash
npm i -g vercel
vercel            # превью
vercel --prod     # прод
```

Или подключить репозиторий на vercel.com — сборка не нужна, `vercel.json` уже настроен на `public/`.

### Firebase Hosting

```bash
npm i -g firebase-tools
firebase login
firebase deploy --only hosting
```

Проект (`violet-3e5a8`) уже прописан в `.firebaserc`. Хостинг отдаёт только
разметку и скрипты — mp3 исключены из деплоя, они уже лежат в бакете того же
проекта.

## Структура

```
public/
  index.html              разметка и шторка настроек
  assets/data.js          ВСЁ учебное содержимое: звуки, слова, рассказы, карточки,
                          пары гласных, переводы вопросов, список озвученных звуков
  assets/app.js           логика: аудио, барабаны, столбики, рассказы, печать
  assets/art.js           SVG-иллюстрации
  assets/styles.css       стили
  audio/manifest.json     {строка: URL в Cloud Storage}
  sw.js                   офлайн-кэш, включая mp3 с чужого origin
scripts/generate-audio.mjs  генерация озвучки и заливка в бакет
```

Чтобы добавить слово или рассказ, правится **только `public/assets/data.js`**. После этого — `npm run audio`: он озвучит новое, не тронет старое и обновит манифест. Манифест нужно закоммитить и выкатить хостинг.
