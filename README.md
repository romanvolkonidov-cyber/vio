# Read with me

Приложение для обучения чтению по-английски по методу **synthetic phonics** — для русскоязычных семей. Мама ведёт занятие, ребёнок читает. 15 минут в день, 12 недель — и ребёнок читает слово, которое видит впервые.

**Живая версия:** _(добавьте ссылку после деплоя)_

---

## Что внутри

| Раздел | Что делает |
|---|---|
| **Старт** | Методика для родителя: как произносить звуки, как читать столбики, маршрут на 12 недель |
| **Наборы 1–4** | 26 звуков в порядке частотности, а не алфавита |
| **Диграфы** | `th` → `ch` → `sh` → `ph` — `th` первым, ему нужно больше всего времени |
| **Немая e** | Тренажёр пар `cap → cape` |
| **Карточки** | Печать 9 карточек на A4 с пунктиром для разреза |

Ключевые механики:

- **Таблицы по столбикам** — в столбике одна гласная, меняются только согласные. Кнопка ▶ подсвечивает слова по очереди и держит темп.
- **Спиннер** — три барабана (onset / vowel / ending) останавливаются по очереди слева направо, слово собирается в порядке чтения.
- **12 рассказов** — каждый использует только пройденные звуки.
- **Прогресс** сохраняется в `localStorage`.

## Озвучка

Голос — **Joana** (ElevenLabs, `qQbLjdSnI72C56rrOF87`): молодой женский, чёткая дикция, категория *informative / educational*.

Все 424 строки записаны **заранее** и лежат в Cloud Storage проекта:

```
gs://violet-3e5a8.firebasestorage.app/audio/<слово>-<хеш>.mp3
```

Приложение читает `public/audio/manifest.json` — это `{строка: URL}` — и играет
готовый файл. Ключей в браузере нет, в ElevenLabs сайт не ходит. Если строки в
манифесте не нашлось, включается голос браузера.

**Почему бакет, а не `public/`.** Аудио живёт отдельно от хостинга: `firebase
deploy` его не трогает и не перезаписывает, деплой остаётся лёгким, а Vercel и
Firebase отдают один и тот же звук. В имени файла — хеш содержимого, поэтому
`Cache-Control` стоит на год: перезаписанная запись получает новый URL, и никто
не остаётся со старыми байтами.

**Предзагрузка.** При открытии набора его озвучка уезжает в кэш браузера, дальше
её отдаёт service worker — второй проход по столбику идёт офлайн и мгновенно.

### Пересобрать озвучку

```bash
cp .env.example .env          # ELEVENLABS_API_KEY + путь к ключу сервисного аккаунта
npm install                   # firebase-admin, нужен только скрипту
npm run audio:dry             # план и стоимость, ничего не тратит
npm run audio                 # догенерирует недостающее и зальёт в бакет
```

| Флаг | Что делает |
|---|---|
| `--dry` | показать план и оценку, ничего не генерировать |
| `--limit=3` | проверить всю связку на трёх файлах |
| `--force` | перезаписать всё заново |
| `--voice=<id>` `--model=<id>` | другой голос или модель |

Скрипт идемпотентен: он сверяет манифест с содержимым бакета и тратит кредиты
только на реально новые строки. Манифест пишется после каждого файла — обрыв
связи ничего не теряет. Осиротевшие после пересборки файлы из бакета удаляются.

`public/audio/*.mp3` — локальный кэш генератора, в git не идёт. Источник правды
— бакет и `manifest.json`.

**Ключи.** `.env` и `service-account.json` в `.gitignore`. В опубликованный сайт
не попадает ни то, ни другое.

> Отдельные звуки (`/k/`, `/t/`, `/æ/`) намеренно не озвучиваются: любой синтез
> читает их как названия букв — «си», «ти» — а это ровно та ошибка, против
> которой построен метод. Звуки произносит взрослый по подсказкам в карточке
> набора.

## Локальный запуск

```bash
npm run dev      # http://localhost:5173
```

Нужен именно http-сервер, а не открытие файла: приложение собрано на ES-модулях.

## Деплой

### Vercel

```bash
npm i -g vercel
vercel            # превью
vercel --prod     # прод
```

Или подключить репозиторий на vercel.com — сборка не нужна, `vercel.json` уже настроен на `public/`.

### Firebase Hosting

```bash
npm i -g firebase-tools
firebase login
firebase deploy --only hosting
```

Проект (`violet-3e5a8`) уже прописан в `.firebaserc`. Хостинг отдаёт только
разметку и скрипты — mp3 исключены из деплоя, они уже лежат в бакете того же
проекта.

## Структура

```
public/
  index.html              разметка и шторка настроек
  assets/data.js          ВСЁ учебное содержимое: звуки, слова, рассказы, карточки
  assets/app.js           логика: аудио, барабаны, столбики, рассказы, печать
  assets/art.js           SVG-иллюстрации
  assets/styles.css       стили
  audio/manifest.json     {строка: URL в Cloud Storage}
  sw.js                   офлайн-кэш, включая mp3 с чужого origin
scripts/generate-audio.mjs  генерация озвучки и заливка в бакет
```

Чтобы добавить слово или рассказ, правится **только `public/assets/data.js`**. После этого — `npm run audio`: он озвучит новое, не тронет старое и обновит манифест. Манифест нужно закоммитить и выкатить хостинг.
